### Level up your real life.

Turn your daily habits into an RPG-style progression system. Build consistency, earn experience, maintain streaks, complete quests, and become a better version of yourself — one level at a time.

## ✨ Features

Habit-Leveling combines habit tracking with RPG-inspired progression to make personal growth more engaging.

- **🎮 XP & Leveling** — Earn experience by completing habits and progress through levels.
- **🔥 Streak Tracking** — Track consistency and keep your momentum going.
- **⚔️ Quests & Challenges** — Turn your goals into missions worth completing.
- **🐉 Raids** — Add challenge-oriented gameplay to your personal progression.
- **🛒 In-App Shop** — Explore a reward system built around your progress.
- **⏳ Focus Sessions** — Make time for focused work and meaningful progress.
- **✨ Interactive UI** — Enjoy visual feedback and effects as you use the app.
- **💾 Progress Persistence** — Keep your progress saved across sessions, according to the app's storage implementation.

> Features and behavior may vary by version. Check the application itself for the current implementation.

---

## 🎯 The Idea

Traditional habit trackers help you record what you do. Habit-Leveling aims to make the process of improving yourself feel like progressing through a game.

Instead of only checking off a task, you can work toward experience, levels, streaks, and challenges.

The goal is simple:

**Build better habits. Stay consistent. Level up in real life.**

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- Git
- A local development server, if required by the project's module loading or browser security requirements

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/TheFool-27/Habit-Leveling.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Habit-Leveling
   ```

3. Run the project using your preferred local development server.

   For example, if you have VS Code installed, you can use the **Live Server** extension to serve the project locally.

4. Open the local URL provided by your development server in your browser.

> If your project supports opening `index.html` directly, you can use that too. Otherwise, use a local server to avoid browser restrictions on JavaScript modules.
